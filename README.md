# Professional Learning Cybersecurity Repository

This repository was created as part of my professional learning activities for 43030 Professional Practice within IT.

The purpose of this activity is to practise using GitHub as a software development and documentation tool. It also supports my learning plan goal of improving my foundational skills in software development tools.

## Learning goals

Through this activity, I aimed to practise:

- creating a GitHub repository
- editing a README file
- committing changes
- organising professional learning evidence
- documenting cybersecurity-related learning

## Relevance to cybersecurity

GitHub is commonly used in IT and cybersecurity roles to manage code, documentation, scripts, workflows and collaborative technical projects. Developing confidence with GitHub helps me prepare for professional environments where version control and clear documentation are required.

## Reflection

This activity helped me understand the basic process of creating a repository and committing changes. It also showed me the importance of clear documentation when presenting technical work.

# Reflection on GitHub Activity

This activity helped me practise basic GitHub skills, including creating a repository, editing files and committing changes.

Before completing this activity, my understanding of GitHub was limited. By creating this repository, I gained more confidence using GitHub as a documentation and version control tool.

This activity links to my Professional Learning Plan because I identified software development tools as an area for improvement. In cybersecurity roles, tools such as GitHub can be used to manage scripts, technical documentation, security reports and collaborative project work.

One area I still need to improve is my ability to use Git through the command line. In future, I would like to practise cloning repositories, creating branches, resolving merge conflicts and using GitHub Actions.
